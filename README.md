# Cybersecurity Asset Inventory System

## Weekly Mini Project – 01

### Objective

The Cybersecurity Asset Inventory System manages an organization's IT assets.

### Features

- Add assets
- Search assets
- Update assets
- Delete assets
- Display all assets
- Track risk level
- Track security status

### Asset Types

- Workstation
- Server
- Router
- Switch
- Application

### Risk Levels

- Low
- Medium
- High
- Critical

### Security Status

- Secure
- Warning
- Vulnerable

### Programming Language

Python
